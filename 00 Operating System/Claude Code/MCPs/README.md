# MCPs de Claude Code

Documentación de los MCP (Model Context Protocol) servers conectados a Claude Code.

Crea un archivo por MCP en esta carpeta documentando:
- Qué hace y para qué se usa
- Cómo está configurado (comando, args, env)
- IDs o cuentas relevantes (sin secretos — esos van en `03 Credenciales/`)

> El estado en vivo de los MCPs se sincroniza solo a `03 Credenciales/Servicios.md`
> al cerrar cada sesión.
