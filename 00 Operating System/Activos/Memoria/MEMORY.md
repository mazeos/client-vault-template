# Memoria de Claude

Espejo de la memoria persistente de Claude Code. Se sincroniza automáticamente
desde `~/.claude/projects/.../memory/` cada vez que Claude escribe o edita un
archivo de memoria, y al cerrar cada sesión.

> No editar a mano — este directorio se sobrescribe en cada sync.
